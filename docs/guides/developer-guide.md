# Руководство разработчика

## Старт проекта
```bash
npm install
npm run dev
```

## Структура проекта
```
src/
├── controllers/   # Бизнес-логика
├── models/        # Модели данных
├── routes/        # Маршруты API
├── middleware/    # Промежуточное ПО
└── services/      # Внешние сервисы
```

## Работа с API
- Все запросы требуют JWT-аутентификации
- Пример заголовка:
  ```json
  Authorization: Bearer <your_token>
  ```

## Тестирование
```bash
npm test
```
- Тесты расположены в папке `tests/`
- Используется Mocha и Chai

## Логирование
- Логи пишутся в `app.log`
- Формат: `[Дата] [Уровень] [Сообщение]`
